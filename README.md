# learn_code

用于快速恢复代码阅读能力与命令行阅读能力。

## 学习目标

- 快速接触多种常见语言，而不是先精通一门。
- 优先读懂 AI 生成的代码和命令：主要逻辑、输入输出、执行影响。
- 先达到“在提示下读懂简单例子”，再逐步提高独立编写能力。

## 第一轮

Python、JavaScript、TypeScript、SQL、Bash/zsh、PowerShell、HTML、CSS、简单 JSX。

## 第二轮

C、C++、Rust、Go、Java、C#。

## 配置与项目文件

JSON、YAML、TOML、Markdown、Dockerfile、package.json、pyproject.toml、Cargo.toml、CMakeLists.txt。

## 索引

- `AGENTS.md`：教学约定。
- `progress.md`：当前进度、需要提示的内容、下次入口。
- `lessons/`：只保存实际学过的短例子与解释；首次课程保存后创建。
