# learn_code

用于快速恢复代码阅读能力与命令行阅读能力。

## 目标

- 快速接触多种常见编程语言与命令行工具。
- 优先读懂 AI 生成的代码和命令：用途、主要逻辑、输入输出、执行影响。
- 先达到“能在提示下读懂简单例子”，再逐步提升到独立编写。
- 不要求先精通一门语言，再学习下一门。

## 第一轮

Python、JavaScript、TypeScript、SQL、Bash/zsh、PowerShell、HTML、CSS、简单 JSX。

## 第二轮

C、C++、Rust、Go、Java、C#。

## 项目与配置文件

JSON、YAML、TOML、Markdown、Dockerfile、package.json、pyproject.toml、Cargo.toml、CMakeLists.txt。

## 文件索引

- `AGENTS.md`：教学约定。
- `progress.md`：当前学习进度与下次入口。
- `lessons/`：实际完成过的短例子与解释。
